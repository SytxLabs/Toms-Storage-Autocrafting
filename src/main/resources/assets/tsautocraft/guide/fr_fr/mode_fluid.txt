Mode : Traitement de fluides

Le stockage de Tom ne gère pas les fluides, ils voyagent donc dans des récipients remplis (seaux, fioles). Comme le traitement, mais les récipients remplis sont vidés dans le réservoir de fluide de la machine et les récipients vides retournent dans le réseau. Un Importer avec un récipient rempli comme filtre remplit des récipients vides depuis la machine et les renvoie dans le réseau. Modèles de remplissage (seau vide -> seau de lave) sur un bloc qui n'a qu'un réservoir, comme un chaudron sous un spéléothème : le Pattern Provider y remplit lui-même les récipients vides et attend qu'il y ait assez de fluide.
